| **Performance** | Local inference, no external API latency |
| **Security** | Fully offline processing — no data leaves the host |
| **Impact** | Privacy-preserving summarization for sensitive documents |
| **Repository** | [View Repo](https://github.com/Hemanthvedantam) |

Runs entirely on a locally hosted LLM via Ollama, making it well suited for summarizing sensitive or confidential documents where sending data to third-party APIs isn't an option.
